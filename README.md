# Sunshine Learning Hub — marketing

Public marketing site for [sunshine-learning.com](https://sunshine-learning.com).

```bash
npm install
npm run dev    # http://localhost:3000
npm run build
npm start
```

**Stack:** Next.js 14 App Router (standalone), GSAP + Motion, Three.js, Lenis.

**Deploy:** Railway production only (`main` → Dockerfile). See `project.md`.

Swap polaroid placeholders in `components/Place.jsx` for real photos under `public/`. Sample quotes live in `lib/data.js`.
